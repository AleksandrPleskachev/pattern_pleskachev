# Лабораторная работа 6: Паттерн Заместитель (Proxy)

## Предметная область
**Филиалы и сотрудники** — контроль доступа и ленивая загрузка данных.

## Паттерн: Заместитель (Proxy)

### Назначение
Объект-посредник контролирует доступ к реальному объекту.

### Проблема
Данные сотрудника могут быть тяжёлыми (загрузка из БД, расчёты). Загружать их при создании каждого сотрудника — расточительно. Плюс нужен контроль доступа: менеджеры видят зарплаты, стажёры — нет.

### Решение
`EmployeeProxy` оборачивает `Employee` и:
1. **Ленивая загрузка** — данные загружаются только при первом обращении
2. **Контроль доступа** — проверяет роль перед возвратом данных

```python
# Создаём заместителя — данные НЕ загружены
proxy = EmployeeProxy("Иванов", "IT", "Разработчик", role="employee")
# proxy._real_employee = None

# Базовая информация — доступна всем, без загрузки
proxy.get_basic_info()  # "Иванов | IT | Разработчик"

# Зарплата — требует загрузки и проверки прав
proxy.get_salary()
# Сначала: загружаем из "БД"
# Потом: если role="employee" → PermissionError!
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Subject | Общий интерфейс | `Employee` / `EmployeeProxy` — одинаковые методы |
| RealSubject | Реальный объект | `Employee` — полные данные |
| Proxy | Заместитель | `EmployeeProxy` — ленивая загрузка + контроль |

### Методы Proxy
| Метод | Загрузка | Проверка доступа |
|---|---|---|
| `get_basic_info()` | Нет | Нет |
| `get_salary()` | Да | Да |
| `get_full_info()` | Да | Да |

### Как запустить
```bash
python lab6/main.py
```

### Что видно в GUI
1. Добавляешь сотрудника с ролью `manager` или `employee`
2. В таблице видно «Данные загружены: Нет»
3. Нажимаешь «Посмотреть данные» → данные загружаются, статус «Да»
4. Если роль `employee` → «Доступ запрещён»
