# Лабораторная работа 6: Паттерн Заместитель (Proxy)

## Предметная область
**Филиалы и сотрудники** — ленивая загрузка данных сотрудников и контроль доступа.

## Паттерн: Заместитель (Proxy)

### Назначение
Обёртывает другой объект и контролирует доступ к нему.

### Проблема
Данные сотрудника могут быть «тяжёлыми» — загрузка из базы данных, расчёты, сетевые запросы. Загружать их сразу при создании объекта неэффективно. Кроме того, нужно контролировать доступ: например, обычный сотрудник не должен видеть зарплаты коллег.

### Решение
Создаётся объект-заместитель `EmployeeProxy`, который:
1. **Lazy load (ленивая загрузка)** — реальные данные загружаются только при первом обращении к ним (`_ensure_loaded()`).
2. **Access control (контроль доступа)** — перед возвратом чувствительных данных проверяется роль пользователя (`_check_access()`).

```python
# Создаём proxy — данные ещё НЕ загружены
proxy = EmployeeProxy("Иванов", "IT", "Разработчик", role="manager")
# _real_employee = None

# Базовая информация — доступна всегда, без загрузки
proxy.get_basic_info()  # "Иванов | IT | Разработчик"

# Полные данные — загружаются лениво
proxy.get_salary()      # [LAZY LOAD] Загружаю данные из БД...
                        # 80000

# Контроль доступа
proxy_employee = EmployeeProxy("Петров", "IT", "Стажёр", role="employee")
proxy_employee.get_salary()  # PermissionError: нет прав
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Subject | Интерфейс реального объекта | `Employee` |
| Proxy | Заместитель с контролем | `EmployeeProxy` |
| RealSubject | Реальный объект | `Employee` |

### Виды контроля
- **LazyProxy** — данные загружаются из «БД» только при первом обращении к зарплате/бонусу/полной информации. `get_basic_info()` работает без загрузки.
- **AccessProxy** — проверка роли. `role="manager"` — полный доступ. `role="employee"` — доступ запрещён (выбрасывается `PermissionError`).

### Как запустить
```bash

```
