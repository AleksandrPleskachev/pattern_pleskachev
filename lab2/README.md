# Лабораторная работа 2: Паттерны Фабричный метод + Прототип

## Предметная область
**Филиалы и сотрудники** — создание разных типов сотрудников и клонирование шаблонов.

## Паттерн 1: Фабричный метод (Factory Method)

### Назначение
Определяет интерфейс для создания объектов, но subclasses (или фабрика) решают, какой класс создать.

### Проблема
Клиент должен знать о всех классах сотрудников и выбирать вручную:
```python
# Без Factory — if/elif в каждом месте
if role == "manager":
    emp = Manager(name, dept, salary)
elif role == "engineer":
    emp = Engineer(name, dept, salary)
```

### Решение
Один метод `create()` — клиент передаёт строку, получает готовый объект:
```python
emp = EmployeeFactory.create("manager", "Иванов", "IT", 80000)
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Product | Создаваемый объект | `Employee` и наследники |
| Creator | Фабрика | `EmployeeFactory._registry` — словарь строка→класс |
| ConcreteCreator | Конкретные продукты | `Manager`, `Engineer`, `Accountant`, `Director` |

### Бонусы по типам
- **Manager** — бонус 20%
- **Engineer** — бонус 15%
- **Accountant** — бонус 10%
- **Director** — бонус 30%

## Паттерн 2: Прототип (Prototype)

### Назначение
Клонирует объекты без привязки к их конкретным классам.

### Проблема
Создание вариаций требует дублирования параметров:
```python
# Без Prototype — дублирование
p1 = EmployeeTemplate("Иванов", "IT", 80000, "Разработчик")
p2 = EmployeeTemplate("Петров", "IT", 80000, "Разработчик")  # скопировал вручную
```

### Решение
Шаблон клонируется с изменением нужных полей:
```python
base = EmployeeTemplate("Иванов", "IT", 80000, "Разработчик")
p1 = base.with_name("Петров")
p2 = base.with_department("HR").with_salary(95000)
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Prototype | Интерфейс клонирования | `EmployeePrototype.clone()` |
| ConcretePrototype | Конкретный клонируемый объект | `EmployeePrototype` |
| Client | Использует клонирование | `.with_name()`, `.with_department()` |

### Как запустить
```bash
python lab2/main.py
```

### Что видно в GUI
- **Factory (центр):** выбираешь тип → нажимаешь «Создать» → видишь какой класс создался
- **Prototype (справа):** шаблон → кнопки `with_*` → клонируют с изменением
