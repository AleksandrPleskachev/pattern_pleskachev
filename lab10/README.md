# Лабораторная работа 10: Паттерны Наблюдатель + Состояние

## Предметная область
**Филиалы и сотрудники** — статус сотрудника и оповещение служб филиала.

## Паттерн 1: Состояние (State)

### Назначение
Объект меняет поведение, когда меняется его внутреннее состояние. Снаружи вызываются те же методы.

### Проблема
Начисление и кадровые действия зависят от статуса: кандидат не получает зарплату, на испытательном сроке оклад урезается, в отпуске платятся отпускные, уволенному начислять нельзя. Набор `if status == ...` в GUI разрастается.

### Решение
`EmployeeSubject` хранит текущий `EmployeeState` и делегирует ему `pay()` и `handle()`. Конкретные состояния: кандидат, испытательный срок, в штате, в отпуске, уволен. Переход делает само состояние.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Context | Хранит текущее состояние | `EmployeeSubject` |
| State | Общий интерфейс | `EmployeeState` |
| ConcreteState | Правила одного статуса | `CandidateState`, `ProbationState`, `ActiveState`, `VacationState`, `DismissedState` |

## Паттерн 2: Наблюдатель (Observer)

### Назначение
Издатель сообщает подписчикам об изменении, не зная, кто они.

### Проблема
Смену статуса и оклада должны увидеть расчётный отдел, журнал кадров и директор. Прямые вызовы трёх окон из кадровой логики связывают модули.

### Решение
`attach()` подписывает наблюдателя. `notify()` рассылает событие всем. Подписчики: `Расчётный отдел`, `Журнал кадров`, `Директор`.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Subject | Издатель | `EmployeeSubject` |
| Observer | Подписчик | `Observer` |

### Как запустить
```bash
python lab10/main.py
```

### Что видно в GUI
Кнопки перехода и «Начислить» вызывают один и тот же код, а результат зависит от статуса. Каждое событие тремя строками появляется в журнале подписчиков.
