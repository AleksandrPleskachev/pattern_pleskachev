# Лабораторная работа 9: Паттерны Посредник + Снимок

## Предметная область
**Филиалы и сотрудники** — связь отделов и откат состава филиала.

## Паттерн 1: Посредник (Mediator)

### Назначение
Убирает прямые связи между объектами: они общаются через один объект-посредник.

### Проблема
Отделы переводят сотрудников и рассылают объявления. Если IT напрямую вызывает «Продажи» и «Кадры», число связей растёт с каждым новым отделом.

### Решение
`Department` знает только `HRMediator`. Найм, перевод и объявление — это `notify(sender, event, data)`. Посредник сам находит отдел назначения.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Mediator | Маршрутизирует события | `HRMediator` |
| Colleague | Отдел | `Department` |

## Паттерн 2: Снимок (Memento)

### Назначение
Сохраняет и восстанавливает состояние объекта, не раскрывая его устройство.

### Проблема
После серии переводов нужно вернуть прежний состав отделов. Копировать списки в GUI нельзя: интерфейс узнает внутреннюю структуру.

### Решение
`BranchOriginator.save()` кладёт глубокую копию штата в `Memento`. `Caretaker` хранит снимки и по кнопке вызывает `restore()`.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Originator | Создаёт и принимает снимок | `BranchOriginator` |
| Memento | Непрозрачное состояние | `Memento` |
| Caretaker | Хранит снимки | `Caretaker` |

### Как запустить
```bash
python lab9/main.py
```

### Что видно в GUI
Слева отделы принимают и переводят людей только через посредника, журнал пишет маршрут. Справа кнопка «Сохранить снимок» фиксирует состав, «Откатить последний» возвращает его.
