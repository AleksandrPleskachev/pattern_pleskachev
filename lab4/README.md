# Лабораторная работа 4: Паттерны Компоновщик + Декоратор

## Предметная область
**Филиалы и сотрудники** — иерархия филиалов/отделов и расчёт надбавок к зарплате.

## Паттерн 1: Компоновщик (Composite)

### Назначение
Позволяет обрабатывать отдельные объекты и их композиции единообразно.

### Проблема
Нужно суммировать зарплаты на разных уровнях: сотрудник → отдел → филиал. Без Компоновщика пришлось бы писать разные обработчики для листа (сотрудник) и контейнера (отдел, филиал).

### Решение
Общий базовый класс `BranchComponent` с методом `get_salary()`. И сотрудник, и отдел, и филиал — все имеют этот метод. Для контейнеров `get_salary()` суммирует зарплаты всех дочерних компонентов.

```python
# Единообразно на любом уровне
branch.get_salary()   # суммирует все отделы
dept.get_salary()     # суммирует всех сотрудников
emp.get_salary()      # возвращает свою зарплату
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Component | Базовый компонент | `BranchComponent` |
| Leaf | Лист дерева | `Employee` |
| Composite | Контейнер | `Department`, `Branch` |

### Структура дерева
```
Головной офис (Branch)
  ├── IT (Department)
  │     ├── Иванов А.А. (80 000)
  │     └── Петрова Б.Б. (60 000)
  ├── Бухгалтерия (Department)
  │     └── Сидорова В.В. (55 000)
  └── Продажи (Department)
        ├── Козлов Г.Г. (50 000)
        └── Новикова Д.Д. (50 000)
```

### Как запустить
```bash
python lab4/main.py
```

### Что видно в GUI
- **Компоновщик (слева):** добавляешь сотрудника в отдел → дерево обновляется → `get_salary()` работает на любом уровне → фонд филиала считается автоматически.

## Паттерн 2: Декоратор (Decorator)

### Назначение
Динамически добавляет объекту новые обязанности без изменения его структуры.

### Проблема
Нужно добавлять надбавки к зарплате (стаж, категория, премия) гибко — не все надбавки всегда нужны, и их можно комбинировать. Через наследование получим взрыв комбинаций.

### Решение
Каждая надбавка — отдельный декоратор, который оборачивает базового сотрудника и добавляет что-то к зарплате. Декораторы можно комбинировать в цепочку.

```python
emp = BaseEmployee("Иванов", 50000)
emp = SeniorityDecorator(emp, years=5)    # +10% за год = +25000
emp = CategoryDecorator(emp, 10000)       # +10000 за категорию
emp = BonusDecorator(emp, 15000)          # +15000 премия
# Итого: 50000 + 25000 + 10000 + 15000 = 100 000
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Component | Базовый интерфейс | `SalaryComponent` |
| ConcreteComponent | Базовый объект | `BaseEmployee` |
| Decorator | Базовый декоратор | `SeniorityDecorator`, `CategoryDecorator`, `BonusDecorator` |

### Надбавки
- **SeniorityDecorator** — 10% от базы за каждый год стажа
- **CategoryDecorator** — фиксированная надбавка за категорию
- **BonusDecorator** — фиксированная премия

### Как запустить
```bash
python lab4/main.py
```

### Что видно в GUI
- **Декоратор (справа):** вводишь ФИО и базу → ставишь чекбоксы надбавок → видишь пошаговый расчёт с логированием каждого декоратора.
