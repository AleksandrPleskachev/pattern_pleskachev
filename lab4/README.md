# Лабораторная работа 4: Паттерны Компоновщик + Декоратор

## Предметная область
**Филиалы и сотрудники** — иерархия организации и надбавки к зарплате.

## Паттерн 1: Компоновщик (Composite)

### Назначение
Составляет объекты в древовидную структуру и работает с ними как с единым целым.

### Проблема
Филиал содержит отделы, отделы содержат сотрудников. Нужно посчитать фонд оплаты на любом уровне:
- Зарплата конкретного сотрудника
- Фонд отдела
- Фонд всего филиала

### Решение
Все компоненты имеют единый интерфейс `get_salary()`:
```python
# Работает на любом уровне дерева
employee.get_salary()   # своя зарплата
dept.get_salary()       # сумма зарплат всех сотрудников
branch.get_salary()     # сумма всех отделов
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Component | Базовый компонент | `BranchComponent` — интерфейс `get_salary()` |
| Leaf | Лист дерева | `Employee` — возвращает свою зарплату |
| Composite | Контейнер | `Department`, `Branch` — суммируют детей |

### Структура дерева
```
Головной офис (300 000)
  IT (140 000)
    Иванов (80 000)
    Петрова (60 000)
  Бухгалтерия (55 000)
    Сидорова (55 000)
```

## Паттерн 2: Декоратор (Decorator)

### Назначение
Динамически добавляет объектам новую функциональность через обёртку.

### Проблема
Нужно добавлять надбавки к зарплате разными способами:
- Стаж: 10% в год
- Категория: фиксированная сумма
- Премия: фиксированная сумма

Наследование создаст взрыв комбинаций.

### Решение
Каждый декоратор оборачивает сотрудника и добавляет надбавку:
```python
emp = BaseEmployee("Иванов", 50000)
emp = SeniorityDecorator(emp, 5)     # +25000 → 75000
emp = CategoryDecorator(emp, 10000)  # +10000 → 85000
emp = BonusDecorator(emp, 15000)     # +15000 → 100000
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Component | Базовый интерфейс | `SalaryComponent.get_salary()` |
| ConcreteComponent | Базовый объект | `BaseEmployee` |
| Decorator | Обёртка | `SeniorityDecorator`, `CategoryDecorator`, `BonusDecorator` |

### Как запустить
```bash
python lab4/main.py
```

### Что видно в GUI
- **Компоновщик (слева):** дерево филиалов → добавляешь сотрудников → фонд пересчитывается автоматически
- **Декоратор (справа):** чекбоксы надбавок → в логе видна цепочка обёрток и рост зарплаты
