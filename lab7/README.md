# Лабораторная работа 7: Паттерны Команда + Итератор

## Предметная область
**Филиалы и сотрудники** — операции с отменой (Undo/Redo) и обход коллекции разными способами.

## Паттерн 1: Команда (Command)

### Назначение
Превращает операции в объекты, которые можно вызывать, отменять и хранить в истории.

### Проблема
Операции (добавить, удалить, изменить зарплату) жёстко связаны с GUI. Нужно поддерживать Undo/Redo — отмену и повтор последних действий.

### Решение
Каждая операция — объект-команда с методами `execute()` и `undo()`. `CommandHistory` хранит историю выполненных команд и стек для Redo.

```python
# Создаём команду
cmd = AddCommand(manager, "Иванов", "IT", "Разработчик", 80000)
# Выполняем
history.execute(cmd)   # → сотрудник добавлен
# Отменяем
history.undo()         # → сотрудник удалён
# Повторяем
history.redo()         # → сотрудник добавлен снова
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Command | Интерфейс команды | `Command` (execute/undo) |
| ConcreteCommand | Конкретная операция | `AddCommand`, `RemoveCommand`, `ChangeSalaryCommand` |
| Invoker | Вызывает команду | `CommandHistory` |
| Receiver | Выполняет операцию | `EmployeeManager` |

### Команды
- **AddCommand** — добавить сотрудника → `undo()` удаляет его
- **RemoveCommand** — удалить сотрудника → `undo()` восстанавливает его
- **ChangeSalaryCommand** — изменить зарплату → `undo()` восстанавливает старую зарплату

### Как запустить
```bash
python lab7/main.py
```

### Что видно в GUI
- **Команда (слева):** добавляешь/удаляешь/меняешь зарплату → в логе видно `[EXECUTE]` → кнопки Undo/Redo отменяют и повторяют действия.

## Паттерн 2: Итератор (Iterator)

### Назначение
Позволяет последовательно обходить коллекцию, не раскрывая её внутреннюю структуру.

### Проблема
Нужно обходить сотрудников по-разному: по алфавиту, по зарплате, по отделу. Если каждый раз писать сортировку и обход в GUI — дублирование кода и привязка к структуре `list`.

### Решение
Каждый способ обхода — отдельный итератор. Клиент вызывает `first()` → `next()` → `is_done()` → `current()`, не зная, как отсортирована коллекция.

```python
# Итератор по алфавиту
it = aggregate.create_alphabetical_iterator()
it.first()
while not it.is_done():
    print(it.current().name)  # Иванов, Петров, Сидоров...
    it.next()

# Итератор по зарплате (по убыванию)
it = aggregate.create_salary_iterator()
it.first()
while not it.is_done():
    print(it.current().salary)  # 95000, 80000, 60000...
    it.next()
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Iterator | Интерфейс итератора | `EmployeeIterator` |
| ConcreteIterator | Конкретный итератор | `AlphabeticalIterator`, `SalaryIterator`, `DepartmentIterator` |
| Aggregate | Создаёт итераторы | `EmployeesAggregate` |

### Типы итераторов
- **AlphabeticalIterator** — сортировка по ФИО (А→Я)
- **SalaryIterator** — сортировка по зарплате (убывание)
- **DepartmentIterator** — сортировка по отделу (А→Я)

### Как запустить
```bash
python lab7/main.py
```

### Что видно в GUI
- **Итератор (справа):** добавляешь сотрудников → нажимаешь «По алфавиту» / «По зарплате» / «По отделу» → видишь список в нужном порядке.
