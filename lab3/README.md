# Лабораторная работа 3: Паттерны Адаптер + Мост

## Предметная область
**Филиалы и сотрудники** — интеграция разных источников данных и гибкая оплата.

## Паттерн 1: Адаптер (Adapter)

### Назначение
Позволяет объектам с несовместимыми интерфейсами работать вместе.

### Проблема
Два источника данных возвращают данные в разных форматах:
- `CSVDataSource.get_employees()` → список словарей
- `JSONDataSource.get_raw_data()` → `{"staff": [...]}`

Клиенту пришлось бы писать разные обработчики для каждого источника.

### Решение
Адаптер оборачивает несовместимый интерфейс и приводит его к ожидаемому:
```python
# Клиент вызывает одинаковый метод
data = csv_source.get_employees()      # список напрямую
data = adapter.get_employees()         # JSON → список через адаптер
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Target | Ожидаемый интерфейс | `DataSource.get_employees()` |
| Adaptee | Несовместимый объект | `JSONDataSource.get_raw_data()` |
| Adapter | Обёртка | `JSONToCSVAdapter` — вызывает `get_raw_data()` и возвращает список |

### Как запустить
```bash
python lab3/main.py
```

## Паттерн 2: Мост (Bridge)

### Назначение
Разделяет абстракцию и реализацию, чтобы они могли меняться независимо.

### Проблема
Без моста — все комбинации через наследование:
```
ШтатныйМесячный, ШтатныйПочасовой, ШтатныйСдельный
КонтрактныйМесячный, КонтрактныйПочасовой, КонтрактныйСдельный
```
2×3 = 6 классов. Новый тип оплаты = ещё 2 класса.

### Решение
Мост разделяет два измерения:
1. **Тип сотрудника** — штатный / контрактный
2. **Способ оплаты** — месячная / почасовая / сдельная

```python
pay = HourlyPay()  # 500 руб/час
emp = Employee("Иванов", "IT", "Разработчик", 40, pay)
emp.get_salary()   # 40 * 500 = 20000
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Abstraction | Основная абстракция | `Employee` |
| Implementor | Реализация | `PayStrategy` + `MonthlyPay`, `HourlyPay`, `PieceworkPay` |
| RefinedAbstraction | Улучшенная абстракция | `Employee` с бонусами |
| ConcreteImplementor | Конкретная реализация | `HourlyPay`, `PieceworkPay` |

### Что видно в GUI
- **Адаптер (справа):** кнопки «Загрузить CSV» и «Загрузить JSON» — данные добавляются одинаково
- **Мост (слева):** выбираешь тип сотрудника + способ оплаты → зарплата считается по-разному
