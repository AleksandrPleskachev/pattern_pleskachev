# Лабораторная работа 8: Паттерн Цепочка обязанностей

## Предметная область
**Филиалы и сотрудники** — согласование повышения зарплаты.

## Паттерн: Цепочка обязанностей (Chain of Responsibility)

### Назначение
Передаёт запрос по цепочке обработчиков, пока один из них его не обработает.

### Проблема
Повышение зарплаты согласуют разные люди, и у каждого свой лимит. Если проверять все лимиты в одном методе GUI, при появлении новой должности придётся переписывать этот метод.

### Решение
Каждый согласующий — отдельный `ApprovalHandler`. Он либо одобряет заявку, если сумма не больше его лимита, либо вызывает `next.handle()`.

```python
team_lead.set_next(dept_head).set_next(hr).set_next(ceo)
decision = team_lead.handle(request, log)
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Handler | Обработчик с ссылкой на следующего | `ApprovalHandler` |
| ConcreteHandler | Конкретный согласующий | Тимлид, руководитель отдела, HR-директор, генеральный директор |
| Request | Запрос | `SalaryRequest` |
| Client | Отправляет запрос в начало цепочки | `ChainApp` |

### Лимиты
- Тимлид — 15 000
- Руководитель отдела — 50 000
- HR-директор — 120 000
- Генеральный директор — 400 000, выше этой суммы заявка отклоняется

### Как запустить
```bash
python lab8/main.py
```

### Что видно в GUI
Вводишь сотрудника и сумму повышения. В журнале видно, кто получил заявку, кто передал её дальше и кто в итоге одобрил.
