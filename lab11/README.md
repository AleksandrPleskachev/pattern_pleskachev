# Лабораторная работа 11: Паттерны Стратегия + Шаблонный метод

## Предметная область
**Филиалы и сотрудники** — расчёт оплаты и печать отчёта по фонду.

## Паттерн 1: Стратегия (Strategy)

### Назначение
Выносит семейство алгоритмов в отдельные объекты и подменяет алгоритм на лету.

### Проблема
Оплата считается по-разному: фиксированный оклад, часы на ставку, оклад плюс процент премии. Ветки `if scheme == ...` внутри расчёта мешают добавить новую схему.

### Решение
`PayStrategy` задаёт `calculate()`. Контекст `PayrollContext` держит текущую стратегию и вызывает её, не зная формулы.

```python
payroll.set_strategy(HourlyStrategy())
payroll.amount(employee)  # hours * rate
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Strategy | Интерфейс алгоритма | `PayStrategy` |
| ConcreteStrategy | Формула | `FixedStrategy`, `HourlyStrategy`, `BonusStrategy` |
| Context | Вызывает стратегию | `PayrollContext` |

## Паттерн 2: Шаблонный метод (Template Method)

### Назначение
Фиксирует скелет алгоритма в базовом классе, а отдельные шаги отдаёт подклассам.

### Проблема
И текстовый, и HTML-отчёт состоят из шапки, строк сотрудников и итога. Если собирать их двумя независимыми функциями, порядок блоков легко разъедется.

### Решение
`ReportTemplate.generate()` всегда вызывает `header()` → `body()` → `footer()`. `TextReport` и `HtmlReport` реализуют только оформление шагов.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| AbstractClass | Скелет `generate()` | `ReportTemplate` |
| ConcreteClass | Шаги отчёта | `TextReport`, `HtmlReport` |

### Как запустить
```bash
python lab11/main.py
```

### Что видно в GUI
При добавлении сотрудника в лог пишется имя стратегии и сумма. Кнопка отчёта показывает, что каркас один, а текст шагов зависит от выбранного вида.
