# Лабораторная работа 1: Паттерн Builder

## Предметная область
**Филиалы и сотрудники** — создание и управление сотрудниками организации.

## Паттерн: Builder (Строитель)

### Назначение
Позволяет пошагово создавать сложные объекты, разделив процесс конструирования от его представления.

### Проблема
Сотрудник имеет 5+ параметров (ФИО, отдел, должность, зарплата, тип). Конструктор с таким количеством аргументов неудобен и подвержен ошибкам:
```python
# Без Builder — трудно читать и легко ошибиться
emp = Employee("Иванов", "IT", "Разработчик", 80000, "штатный", True)
```

### Решение
Builder собирает объект по шагам с именованными методами:
```python
emp = (EmployeeBuilder()
           .name("Иванов")
           .department("IT")
           .position("Разработчик")
           .salary(80000)
           .emp_type("штатный")
           .build())
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Product | Создаваемый объект | `Employee` — неизменяемый, все поля final |
| Builder | Интерфейс сборки | `EmployeeBuilder` — chain-методы, возвращают `self` |
| ConcreteBuilder | Конкретная сборка | Тот же `EmployeeBuilder` |
| Director | Управляет сборкой | `build()` — финализирует и валидирует |

### Признаки паттерна в коде
1. `build()` создаёт готовый продукт из накопленных данных
2. Каждый метод возвращает `self` для цепочечных вызовов
3. `build()` валидирует данные перед созданием объекта
4. Product неизменяем после создания

### Как запустить
```bash
python lab1/main.py
```
