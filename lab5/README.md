# Лабораторная работа 5: Паттерны Фасад + Приспособленец

## Предметная область
**Филиалы и сотрудники** — упрощение расчёта зарплаты и экономия памяти через общие отделы.

## Паттерн 1: Приспособленец (Flyweight)

### Назначение
Экономит память, разделяя общие данные между множеством объектов.

### Проблема
Если у компании 1000 сотрудников и 5 отделов, то каждый сотрудник хранит копию данных отдела (название, бюджет, менеджер). Это 1000 копий одних и тех же данных — впустую.

### Решение
Отделы хранятся один раз в кэше (`DepartmentFactory`). Каждый сотрудник хранит ссылку на общий объект отдела, а не его копию.

```python
# Первый запрос — создаёт отдел
dept1 = DepartmentFactory.get_department("IT", 500000, "Иванов")
# Второй запрос — возвращает тот же объект
dept2 = DepartmentFactory.get_department("IT", 500000, "Иванов")
# dept1 is dept2 → True (один и тот же объект в памяти)
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Flyweight | Легковесный объект | `DepartmentFlyweight` |
| FlyweightFactory | Фабрика для кэширования | `DepartmentFactory._departments` |
| Client | Использует отделы | `Employee` хранит ссылку на `DepartmentFlyweight` |

### Как запустить
```bash
python lab5/main.py
```

### Что видно в GUI
- **Приспособленец (слева):** добавляешь сотрудников в разные отделы → статистика показывает, сколько отделов создано реально (не сколько раз они упомянуты).

## Паттерн 2: Фасад (Facade)

### Назначение
Предоставляет простой интерфейс к сложной подсистеме.

### Проблема
Расчёт зарплаты включает множество шагов: НДФЛ 13%, страховые 30%, бонусы, вычеты за детей. Клиенту пришлось бы знать о каждом калькуляторе и вызывать их вручную.

### Решение
Один метод `calculate_payroll()` — внутри себя вызывает все необходимые расчёты и возвращает готовый результат.

```python
# БЕЗ фасада — клиент знает о всех деталях
tax = TaxCalculator()
bonus_calc = BonusCalculator()
deduction = DeductionCalculator()
income_tax = tax.calculate_income_tax(80000)
social_tax = tax.calculate_social_tax(80000)
bonus = bonus_calc.calculate_bonus(80000, 10)
ded = deduction.calculate_deductions(80000, True)
total = 80000 + bonus - income_tax - social_tax - ded

# С ФАСАДОМ — один метод
result = facade.calculate_payroll(80000, bonus_percent=10, has_children=True)
# Внутри: налоги, страховые, бонусы, вычеты — всё посчитано
```

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Facade | Упрощённый интерфейс | `PayrollFacade` |
| Subsystems | Подсистемы | `TaxCalculator`, `BonusCalculator`, `DeductionCalculator` |

### Расчёты
- **НДФЛ** — 13% от зарплаты
- **Страховые** — 30% от зарплаты
- **Премия** — задаётся в процентах
- **Вычеты** — 4% при наличии детей

### Как запустить
```bash
python lab5/main.py
```

### Что видно в GUI
- **Фасад (справа):** вводишь зарплату, премию, галочку «есть дети» → видишь полный расчёт и сравнение: «без фасада» (много строк кода) vs «с фасадом» (один метод).
