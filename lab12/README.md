# Лабораторная работа 12: Архитектурный паттерн MVC

## Предметная область
**Филиалы и сотрудники** — учёт штата, фильтр по отделу и фонд оплаты.

## Паттерн: MVC (Model-View-Controller)

### Назначение
Делит приложение на данные, отображение и обработку действий пользователя.

### Проблема
В исходной программе и список сотрудников, и кнопки, и расчёт фонда живут в одном классе окна. Форму нельзя переиспользовать, а правила проверки зарплаты перемешаны с `grid()`.

### Решение
- `EmployeeModel` хранит список и считает фонд. Tkinter ей неизвестен.
- `EmployeeView` создаёт виджеты и вызывает колбэки `on_add`, `on_remove`, `on_filter`.
- `EmployeeController` проверяет ввод, меняет модель и просит вид перерисоваться.

### Участники
| Участник | Роль | В коде |
|---|---|---|
| Model | Данные и операции | `EmployeeModel` |
| View | Интерфейс | `EmployeeView` |
| Controller | Реакция на действия | `EmployeeController` |

### Как запустить
```bash
python lab12/main.py
```

### Что видно в GUI
В логе под таблицей каждое действие помечено слоем: контроллер читает форму, вызывает модель и обновляет вид. Фильтр отдела не удаляет записи, а только выбирает, что показать.
